# DukaanOS

DukaanOS is a modern business management and business intelligence platform designed for small and medium-sized enterprises (SMEs) to simplify daily operations and provide actionable data-driven insights.

## Current Project Status
- **Phase 1**: Master Product Specification & Architecture (Completed)
- **Phase 2**: Project Foundation (Completed)
- Next up: Domain logic and dashboard implementation.

## Technology Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- Auth.js
